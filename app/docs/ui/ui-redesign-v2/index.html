O que mudou da v1 para cá: cor primária deixou de ser roxo/indigo e virou o neutro real do projeto (quase preto no claro, quase branco no escuro), fonte trocou de Inter para Montserrat, badges de status agora seguem exatamente o componente real (destructive é vermelho sólido, sucesso/aviso são tons claros), a sidebar ganhou o visual "flutuante" do componente real, e os cards de indicador replicam o overview-cards.tsx real (blob de gradiente + chip colorido). Em Encomendas, o card "Tipos de encomenda" foi removido e o ícone de Alimento agora é um sanduíche. A composição das telas em si não mudou — só a pele. A v1 continua intacta em ../ui-redesign/ para comparação lado a lado.
